# 🔤 Guess the Word – C Version

A simple **word guessing game** written in C, where the player has **only one chance** to guess the correct word. Perfect for beginners learning how to handle user input, strings, and basic logic in C.

## 🎯 Features
- One-shot full word guessing game
- Simple and clean terminal interface
- Minimal and easy-to-understand C code

## 🛠 Built With
- C (Standard Library)
- GCC / Clang for compilation

## 🚀 Getting Started

### 🔧 Compilation
To compile the program:

```bash
gcc guess_word.c -o guess_word
```

### ▶️ Run the Game
```bash
./guess_word
```

You will be prompted to guess the word. You only get **one try**—choose wisely!

## 🧠 Example Output
```
Welcome to Guess the Word!
Enter your guess: apple
Incorrect! The correct word was: peach
```
